# nx-toolbox 2.0.0 预览版 2

> 换包不会再误删电脑硬盘，卡上的游戏默认保留；新增换卡工具。

[English →](v2.0.0-preview.2-en.md)

---

## 概览

这一版主要修了换包的一个严重问题：如果电脑上的数据盘根目录有 Nintendo、emuMMC 之类的文件夹，旧版会把它当成存储卡，按“不在白名单里就清除”把盘上的其他文件删掉。现在只有可移动存储卡才会被识别和完整清理。

同时新增「换卡」工具，在电脑上把旧卡的内容搬到新卡。

这是预览版，可能有问题。更新存储卡前请保持「先创建快照」开着；换卡前请先备份旧卡。

## 更新内容

- **只认可移动存储卡**：自动识别只列出读卡器里的卡和 U 盘，电脑硬盘、移动硬盘就算有大气层文件夹也不会列出来
- **拒绝电脑硬盘**：根目录有 Windows、Program Files、Users 等，或者包含用户文件夹、系统文件夹的位置，直接不让用
- **非存储卡只动大气层**：手动选了不是存储卡的位置时，只清理大气层文件夹里的黑名单，其他文件一概不动
- **开始前确认**：每次开始前都会显示位置、要清掉和装入的文件数量；确认后卡上内容有变化就不会开始
- **保留游戏和影音**：卡上任何位置的 nsp、nsz、xci、xcz、模拟器 ROM、视频和音乐默认保留；取消保留时会提醒它们不进快照
- **新工具「换卡」**：在电脑上把旧卡搬到新卡，新卡只要放得下旧卡的占用就行；支持安卓和 Linux 分区、双虚拟系统，可以调大或调小虚拟系统；只有一个读卡器时可以经电脑中转

## 安装

[v2.0.0-preview.2 Release 页面](https://github.com/Lili679280/nx-toolbox/releases/tag/v2.0.0-preview.2)提供：

- `NXToolbox-2.0.0-preview.2.exe`：安装程序，下载后双击安装

已经装了 2.0 预览版 1 的话，打开工具箱会提示更新。还在用 1.0 的话，打开 1.0 时会提示升级。需要 Windows 10 或 11，以及 WebView2 运行时（Windows 11 已内置）。

当前 EXE 尚未进行代码签名，运行前请核对页面公布的 SHA-256。

## 安全提示

换包工具会删除和覆盖存储卡上的文件，不在白名单里的内容默认会被清除。开始前请核对确认框里的位置和数量。「正版系统和虚拟系统」、游戏安装包、视频和音乐体积太大，不会进入快照。

换卡工具需要管理员权限，会直接写入新卡的分区表和扇区，新卡上原有的内容会被覆盖。请先确认选对了新卡，并备份旧卡。

报告与操作安全说明请查看 [SECURITY.md](https://github.com/Lili679280/nx-toolbox/blob/v2/SECURITY.md)。内置第三方内容继续遵循各自许可条款，详情请查看 [THIRD_PARTY_NOTICES.md](https://github.com/Lili679280/nx-toolbox/blob/v2/THIRD_PARTY_NOTICES.md)。
