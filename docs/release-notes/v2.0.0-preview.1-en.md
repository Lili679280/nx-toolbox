# nx-toolbox 2.0.0 Preview 1

> The first preview of the rewritten 2.0: a new interface and simpler swap rules.

[中文版 →](v2.0.0-preview.1-zh-CN.md)

---

## Overview

2.0 is a rewrite of the toolbox. The launcher and each tool now open in their own windows with a new interface. The swap tool's rules are reduced to three, and you can see which files will change before an update starts.

This is a preview and may have problems. Keep "create a snapshot first" turned on before updating a storage card. The interface is in Simplified Chinese.

## What's New

- **New interface**: a launcher plus separate tool windows
- **Simpler swap rules**: blacklisted paths are removed, whitelisted paths are kept, everything else is removed before the new package is installed; every item can be changed by hand
- **Preview before updating**: browse what will be kept and removed, folder by folder
- **Online packages**: only the file list is read, without downloading the whole archive first
- **Write verification**: every installed file is checked
- **List sources**: reads `whitelist.txt` and `blacklist.txt` shipped in the package or on the card
- **Online update**: the download is checked against its SHA-256
- **Snapshots, firmware, and the log**: all still there

## Installation

The [v2.0.0-preview.1 Release page](https://github.com/Lili679280/nx-toolbox/releases/tag/v2.0.0-preview.1) provides:

- `NXToolbox-2.0.0-preview.1.exe`: the installer; download it and run it

You can choose the install location and whether to add desktop and Start menu shortcuts. It installs for the current user only and does not need administrator rights. Open the toolbox from its shortcut afterwards; to uninstall, run the installer again or use "Installed apps" in Windows Settings. Requires Windows 10 or 11 with the WebView2 runtime (built into Windows 11).

The executable is currently unsigned. Verify the SHA-256 published on this page before running it.

If you already use 1.0, it will offer the upgrade when you open it and complete it after you confirm.

## Safety

The swap tool deletes and overwrites files on the storage card, and anything not on the whitelist is removed by default. Confirm you picked the right card and review the list before updating. The Nintendo and emuMMC folders are too large to be included in snapshots. See [SECURITY.md](https://github.com/Lili679280/nx-toolbox/blob/v2/SECURITY.md) for reporting and operational safety notes.

Bundled third-party content keeps its own license terms; see [THIRD_PARTY_NOTICES.md](https://github.com/Lili679280/nx-toolbox/blob/v2/THIRD_PARTY_NOTICES.md).
