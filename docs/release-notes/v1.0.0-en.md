# nx-toolbox v1.0.0

> First public release of the extensible Windows toolbox for Nintendo Switch utilities.

[中文版 →](v1.0.0-zh-CN.md)

---

## Overview

This release establishes nx-toolbox as a shared launcher and repository for a growing collection of focused Switch utilities. The first available direction is the SD Card Package Tool, while the launcher and module structure are designed to accept additional tools in later releases.

## Included

- **Toolbox launcher** — one entry point for current and future modules
- **SD Card Package Tool** — whitelist-based cleanup, preview, backup, and package updates
- **Snapshots** — pre-update backup metadata and restore workflow
- **Package and firmware workflows** — local and configured online installation
- **Version detection** — Atmosphère and firmware compatibility information
- **Application updater** — version checks, downloads, replacement, and restart
- **Project documentation** — separate English and Simplified Chinese README files
- **Repository standards** — MIT License, third-party notices, security policy, contribution guide, and GitHub templates

## Installation

GitHub provides **Source code (zip)** and **Source code (tar.gz)** archives on the [v1.0.0 release page](https://github.com/Lili679280/nx-toolbox/releases/tag/v1.0.0). To run from a Git clone:

```powershell
git clone https://github.com/Lili679280/nx-toolbox.git
Set-Location nx-toolbox
python nx_toolbox.py
```

## Safety

SD-card cleanup and installation operations can delete or overwrite data. Keep an independent backup, verify the selected drive and package, and review the operation preview before continuing. See [SECURITY.md](../../SECURITY.md) for reporting and operational guidance.
