# nx-toolbox v1.0.0

> 面向 Nintendo Switch 实用工具的可扩展 Windows 工具箱首个公开版本。

[English →](v1.0.0-en.md)

---

## 概览

这个版本确立了 nx-toolbox 的核心定位：为持续增加的 Switch 实用工具提供统一启动器与共同仓库。当前第一个可用方向是 SD 卡换包工具，启动器与模块结构则为后续加入更多工具保留了扩展空间。

## 内置内容

- **工具箱启动器**：当前与未来模块的统一入口
- **SD 卡换包工具**：基于白名单的清理、预览、备份和整合包更新
- **快照管理**：更新前备份元数据与恢复流程
- **整合包与固件流程**：本地或配置的在线安装
- **版本检测**：Atmosphère 与固件兼容信息
- **应用更新器**：版本检查、下载、替换与重启
- **项目文档**：独立的英文和简体中文 README
- **仓库规范**：MIT 许可证、第三方声明、安全策略、贡献指南与 GitHub 模板

## 安装

GitHub 会在 [v1.0.0 Release 页面](https://github.com/Lili679280/nx-toolbox/releases/tag/v1.0.0)自动提供 **Source code (zip)** 和 **Source code (tar.gz)** 源码包。也可以克隆仓库后直接运行：

```powershell
git clone https://github.com/Lili679280/nx-toolbox.git
Set-Location nx-toolbox
python nx_toolbox.py
```

## 安全提示

SD 卡清理与安装操作可能删除或覆盖数据。请保留独立备份、确认所选磁盘与安装包，并在继续前检查操作预览。报告与操作安全说明请查看 [SECURITY.md](../../SECURITY.md)。

内置第三方内容继续遵循各自许可条款，详情请查看 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。
