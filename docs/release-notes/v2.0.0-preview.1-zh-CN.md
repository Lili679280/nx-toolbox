# nx-toolbox 2.0.0 预览版 1

> 整个重做的 2.0 的第一个预览版：新界面，换包规则更简单。

[English →](v2.0.0-preview.1-en.md)

---

## 概览

2.0 把工具箱从头重写了一遍。启动器和每个工具现在是各自独立的窗口，界面换成了新的样式；换包工具的规则简化成三条，更新前就能看到会改动哪些文件。

这是预览版，可能有问题。更新存储卡前请保持「先创建快照」开着。

## 更新内容

- **全新界面**：启动器加独立的工具窗口
- **换包规则简化**：黑名单清除，白名单保留，其余清除后装上新的整合包；每一项都可以手动改
- **更新前预览**：按文件夹一层层查看会保留和会清除的文件
- **在线整合包**：只读取文件清单，不用先下载整个包
- **写入校验**：装入的每个文件都会核对
- **名单来源**：读取整合包和存储卡自带的 `whitelist.txt`、`blacklist.txt`
- **在线更新**：下载后核对 SHA-256
- **快照、固件、日志**：都保留

## 安装

[v2.0.0-preview.1 Release 页面](https://github.com/Lili679280/nx-toolbox/releases/tag/v2.0.0-preview.1)提供：

- `NXToolbox-2.0.0-preview.1.exe`：安装程序，下载后双击安装

可以选安装位置和要不要桌面、开始菜单快捷方式，只安装给当前用户，不需要管理员权限。装好后从快捷方式打开；要卸载的话，再运行一次安装程序，或者在系统设置的「已安装的应用」里卸载。需要 Windows 10 或 11，以及 WebView2 运行时（Windows 11 已内置）。

当前 EXE 尚未进行代码签名，运行前请核对页面公布的 SHA-256。

已经在用 1.0 的话，打开 1.0 时会提示升级，确认后自动完成。

## 安全提示

换包工具会删除和覆盖存储卡上的文件，不在白名单里的内容默认会被清除。请确认选对了存储卡，并在更新前检查列表。「正版系统和虚拟系统」体积太大，不会进入快照。报告与操作安全说明请查看 [SECURITY.md](https://github.com/Lili679280/nx-toolbox/blob/v2/SECURITY.md)。

内置第三方内容继续遵循各自许可条款，详情请查看 [THIRD_PARTY_NOTICES.md](https://github.com/Lili679280/nx-toolbox/blob/v2/THIRD_PARTY_NOTICES.md)。
