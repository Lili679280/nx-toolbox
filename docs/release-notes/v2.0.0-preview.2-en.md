# nx-toolbox 2.0.0 Preview 2

> The swap tool no longer wipes computer drives, games on the card are kept, and a new card migration tool.

[中文版 →](v2.0.0-preview.2-zh-CN.md)

---

## Overview

This release fixes a serious problem in the swap tool: if a computer data drive had a Nintendo or emuMMC folder at its root, the previous version treated it as a memory card and removed everything else on it under the "remove anything not whitelisted" rule. Now only removable memory cards are detected and fully cleaned.

It also adds a "Card migration" tool that moves an old card to a new one on the computer.

This is a preview and may have problems. Keep "create a snapshot first" turned on before updating a card, and back up the old card before migrating. The interface is in Simplified Chinese.

## What's New

- **Removable cards only**: automatic detection lists only cards in a card reader and USB flash drives; computer drives and USB hard drives are never listed, even with Atmosphere folders on them
- **Computer drives refused**: locations whose root has Windows, Program Files, Users and similar, or that contain the user or system folders, cannot be used
- **Atmosphere only elsewhere**: on a location that is not a removable card, only blacklisted items inside the Atmosphere folders are removed and nothing else is touched
- **Confirm before starting**: every run shows the location and how many files will be removed and installed, and does not start if the card changed after confirming
- **Games and media kept**: nsp, nsz, xci, xcz, emulator ROMs, videos and music anywhere on the card are kept by default; unticking them warns that they are not snapshotted
- **New card migration tool**: moves an old card to a new one that only needs room for what the old card uses; supports Android and Linux partitions and dual emuMMC, can grow or shrink emuMMC, and can go through the computer when there is only one card reader

## Installation

The [v2.0.0-preview.2 Release page](https://github.com/Lili679280/nx-toolbox/releases/tag/v2.0.0-preview.2) provides:

- `NXToolbox-2.0.0-preview.2.exe`: the installer; download it and run it

If 2.0 Preview 1 is installed, the toolbox offers the update when opened. If you are on 1.0, it offers the upgrade when opened. Requires Windows 10 or 11 and the WebView2 runtime (built into Windows 11).

The EXE is not code-signed yet. Check the SHA-256 below before running it.

## Safety

The swap tool removes and overwrites files on the card, and anything not whitelisted is removed by default. Check the location and counts in the confirmation before starting. The genuine system and emuMMC, game packages, videos and music are too large to go into snapshots.

The card migration tool needs administrator rights and writes the new card's partition table and sectors directly, overwriting whatever is on it. Make sure the right card is selected and back up the old card first.
